# 06. Abast del projecte

## Inclòs en l'MVP

- Registre i inici de sessió.
- Publicació i gestió de videojocs propis.
- Incorporació d'informació, imatges i fitxers dels videojocs.
- Catàleg públic de videojocs.
- Cerca i filtres bàsics.
- Fitxa informativa de cada videojoc.
- Descàrrega dels fitxers publicats.
- Execució al navegador de builds web compatibles amb WebGL.

## Roadmap futur

Les funcionalitats següents es podran valorar després de completar l'MVP:

- Valoracions i comentaris.
- Sistema de favorits.
- Estadístiques de visites.
- Gestió avançada de versions.
- Perfils personalitzables.
- Recomanacions personalitzades.

## Fora de l'abast actual

- Venda de videojocs.
- Integració de passarel·les de pagament.
- Aplicació d'escriptori pròpia.
- Execució remota de videojocs mitjançant streaming.
- Gestor avançat de descàrregues que permeti pausar, reprendre i programar descàrregues.
- Sincronització del progrés dels videojocs entre dispositius.

## Limitacions tècniques

- La plataforma no convertirà automàticament videojocs d'escriptori a WebGL.
- L'execució al navegador només estarà disponible per als videojocs que disposin d'una build web compatible.
- Inicialment es preveu utilitzar fitxers ZIP per a la publicació dels videojocs.
- Els formats admesos, la mida màxima dels fitxers i els procediments de validació s'hauran de concretar durant el disseny.
- La gestió dels fitxers haurà de tenir en compte la seguretat, l'emmagatzematge, l'extracció i la distribució dels videojocs.

## Criteri de control de l'abast

Les funcionalitats noves s'hauran de valorar segons el temps disponible, la seva relació amb els objectius de l'MVP i la complexitat tècnica que incorporin.

La descàrrega de videojocs i l'execució de builds web compatibles són funcionalitats de l'MVP, no funcionalitats futures.
