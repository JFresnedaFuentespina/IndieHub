# 02. Necessitats identificades

Les necessitats següents parteixen de l'anàlisi inicial del projecte i de l'observació de plataformes existents. Es consideren hipòtesis de treball que es podran validar o ajustar durant el desenvolupament.

| ID | Necessitat | Persones afectades | Prioritat | Origen o evidència inicial |
|---|---|---|---|---|
| N1 | Disposar d'un espai accessible per publicar i gestionar videojocs propis. | Desenvolupadors | Alta | Anàlisi del problema que vol resoldre IndieHub. |
| N2 | Presentar els videojocs amb informació clara. | Desenvolupadors i jugadors | Alta | Necessitat de descriure els jocs i facilitar-ne la consulta. |
| N3 | Descobrir videojocs nous segons els interessos dels usuaris. | Jugadors | Alta | Anàlisi de les necessitats de descoberta i consulta de videojocs. |
| N4 | Accedir als videojocs mitjançant la descàrrega dels fitxers publicats. | Jugadors | Alta | Necessitat identificada en la proposta inicial i en l'anàlisi de les opcions de distribució. |
| N5 | Provar videojocs directament des del navegador quan disposin d'una build web compatible amb WebGL. | Jugadors | Alta | Necessitat identificada en la proposta inicial i en les proves tècniques previstes. |

## Evidències pendents de reforçar

Per millorar la justificació de les necessitats, es proposa:

- Analitzar les funcionalitats de plataformes existents, com ara itch.io i Steam.
- Comparar les opcions de publicació, descoberta, descàrrega i execució web.
- Registrar els resultats de les proves tècniques amb builds web de videojocs.
- Si és viable, recollir l'opinió de possibles usuaris mitjançant preguntes breus.

No es consideren realitzades entrevistes o enquestes fins que l'equip les dugui a terme.

## Criteri de priorització

Les necessitats tenen prioritat alta perquè estan directament relacionades amb la proposta de valor i amb les tres funcionalitats principals de l'MVP.

Les necessitats relacionades amb la interacció social, com ara valorar o comentar videojocs, es reserven per a versions futures.
